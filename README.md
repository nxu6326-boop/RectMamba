# RectMamba

Official repository for **RectMamba: Hierarchical Correspondence Rectification and Cross-Conditioned Bidirectional State-Space Fusion for Multimodal Remote Sensing Segmentation**.

## Overview

RectMamba is a multimodal semantic segmentation framework for very-high-resolution remote sensing imagery. It integrates optical imagery and digital surface model (DSM) data through:

- Hierarchical Correspondence Rectification (HCR);
- Cross-Conditioned Bidirectional State-Space Modules (CC-BSSM);
- progressive multimodal feature decoding.

The framework is evaluated on the ISPRS Vaihingen and Potsdam 2-D semantic labeling datasets.
